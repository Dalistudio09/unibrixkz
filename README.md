# Unibrix.kz

Сайт слаботочных систем в Караганде: видеонаблюдение, охрана, пожарная сигнализация, СКУД и домофоны.

## Установка и сборка

```bash
npm i
npm run build
```

Локально:

```bash
npm run dev
```

## Vercel

- Install Command: `npm i`
- Build Command: `npm run build`
- Распакуйте архив так, чтобы `package.json` лежал в корне проекта, без лишней вложенной папки.
